# OSSec Slidev lectures

A portable, catalog-driven Slidev skeleton for a multi-topic course. The catalog currently contains three independently runnable lecture decks in the first two of five topics; the remaining topics are ready for lectures to be added.

## Prerequisites

- Node.js 20.12+ (use the version in `.nvmrc`)
- npm 10+ (or a compatible package manager)

Install dependencies once per machine:

```sh
npm install
npm run setup:browser
```

`setup:browser` downloads Chromium used by PDF export. It is required on both Linux and Windows, and its downloaded files are intentionally not committed.

## Everyday commands

```sh
npm run list
npm run dev -- 01-physical-security/01-physical-security
npm run build -- 02-identity-and-access-management/02-classical-unix-mechanisms
npm run export -- 02-identity-and-access-management/03-pam --format all
```

`build` creates a static HTML application at `dist/<topic>/<lecture>/`. `export --format pdf` writes a PDF beside it; `--format html`, `--format pdf`, and `--format all` are supported. Use `npm run build:all` or `npm run export:all` for the complete course.

The commands run through Node.js rather than shell scripts, making the same invocations work in PowerShell, cmd, Bash, and Linux CI.

## Add a lecture

1. Add the topic and lecture metadata to `lectures.json`.
2. Create `materials/lectures/<topic-id>/<lecture-id>/slides.md` from an existing starter.
3. Run `npm run list` to validate that the catalog and source tree agree.

Each `slides.md` is self-contained. Shared visual choices belong in `theme/`; lecture-specific images and components belong under that lecture's `assets/` and `components/` directories.

## Repository map

```text
materials/lectures/   one independently buildable Slidev entry per lecture
theme/                shared styles, future components, layouts, assets
scripts/              cross-platform catalog, build, and export launcher
dist/                 generated HTML/PDF artifacts (ignored)
lectures.json         course and lecture source of truth
```

For CI, commit the `package-lock.json` generated by the first `npm install`, then run `npm ci`, `npx playwright install --with-deps chromium` (Linux only), and `npm run export:all`. On Windows runners, use `npm run setup:browser` without `--with-deps`.


===== Создаём пользователя bob и добавляем его в группы =====

# useradd -m -s /bin/bash bob

# usermod -aG sudo,users,adm bob

===== Просмотр групп: команда groups =====

# groups bob
bob : bob adm sudo users

===== Просмотр групп: команда id (числовые GID + имена) =====

# id bob
uid=1001(bob) gid=1001(bob) groups=1001(bob),4(adm),27(sudo),100(users)

===== Соответствующие строки в /etc/group =====

# grep -E '^(bob|sudo|users|adm):' /etc/group
adm:x:4:ubuntu,bob
sudo:x:27:ubuntu,bob
users:x:100:bob
bob:x:1001:

Первичная группа bob (GID из /etc/passwd, поле 4):

# grep '^bob:' /etc/passwd
bob:x:1001:1001::/home/bob:/bin/bash
Вторичные группы перечислены в 4-м поле строк /etc/group.

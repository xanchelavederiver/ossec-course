
===== 1) Один пароль, разные алгоритмы =====

# openssl passwd -1     'CorrectHorse'   # MD5-crypt         ($1$)
$1$4S0/5bVD$yngQmzrssjVQEZdIkEoMi/

# openssl passwd -5     'CorrectHorse'   # SHA-256-crypt     ($5$)
$5$u7vKmRzt3omDrKLW$Ru8DnC5mQR1S9VHSpyZPb5UzXbQAGlrHuHW.DHqsHPB

# openssl passwd -6     'CorrectHorse'   # SHA-512-crypt     ($6$)
$6$KdbMU22uo3GTctK0$ezlty11dMvXfPspQD5HPCJJ.HOU559Nbt.xDunJGIma3DsQ78D6xkg4cKl2DX98qoNVnyFsFKvbjJN1Ybv9ge0

# openssl passwd -aixmd5 'CorrectHorse'  # AIX MD5
HVDyvKM.$qVptQ3MIuAlPVU0eSdA5q/

Соль генерируется случайно => при каждом запуске хэш другой,
хотя пароль один и тот же.

===== 2) Один пароль + фиксированная соль -> идентичный хэш =====
Соль задаётся ключом -salt. Формат SHA-512: $6$<соль>$<хэш>

# openssl passwd -6 -salt 'FixedSalt01' 'CorrectHorse'
$6$FixedSalt01$9owNUlCb4xjb152ePPnGJt5XNzs.3rY2QQFDwMXj32h1vvxg21avHv8hnyg1zBaS0OtgP6Eeiyt9QNrpnRtEl1

# openssl passwd -6 -salt 'FixedSalt01' 'CorrectHorse'
$6$FixedSalt01$9owNUlCb4xjb152ePPnGJt5XNzs.3rY2QQFDwMXj32h1vvxg21avHv8hnyg1zBaS0OtgP6Eeiyt9QNrpnRtEl1

Оба вызова дали ОДИН И ТОТ ЖЕ результат — хэш детерминирован по
паре (пароль, соль). Именно так login/passwd проверяют пароль:
берут соль из сохранённого хэша и пересчитывают хэш заново.

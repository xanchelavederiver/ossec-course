
===== Подготовка: ssh-сервер и учётная запись grace для реальных входов =====

===== Классическое состояние Ubuntu 26.04: файлы пусты, утилит нет =====

# ls -l /run/utmp /var/log/wtmp /var/log/btmp /var/log/lastlog 2>&1 || true
ls: cannot access '/run/utmp': No such file or directory
-rw-rw---- 1 root utmp 0 Sep 27 10:24 /var/log/btmp
-rw-rw-r-- 1 root utmp 0 Sep 27 10:24 /var/log/lastlog
-rw-rw-r-- 1 root utmp 0 Sep 27 10:24 /var/log/wtmp

# command -v last lastb utmpdump lastlog || echo 'классические утилиты отсутствуют'
классические утилиты отсутствуют

===== Устанавливаем замену: wtmpdb и lastlog2 (+ их PAM-модули) =====

# grep -hE 'wtmpdb|lastlog2' /etc/pam.d/common-session
session	optional			pam_wtmpdb.so 
session	optional			pam_lastlog2.so 

===== Успешный вход по ssh (PAM-сессия пишет wtmpdb и lastlog2) =====

# sshpass -p gracepw ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null grace@127.0.0.1 'echo вошли как $(whoami)'
Warning: Permanently added '127.0.0.1' (ED25519) to the list of known hosts.
вошли как grace

===== НЕУДАЧНАЯ попытка входа =====

# sshpass -p WRONG ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null grace@127.0.0.1 true 2>&1 | tail -1 || true
Permission denied, please try again.

===== История входов: wtmpdb last (журнал — база SQLite) =====

# wtmpdb last -n 3
grace    ssh          127.0.0.1        Mon Oct  5 11:24 - 11:24  (00:00)

wtmpdb begins Mon Oct  5 11:24:48 2026

===== Последний вход каждого пользователя: lastlog2 =====

# lastlog2 -u grace
Username         Port     From                                       Latest 
grace            ssh      127.0.0.1                                  Mon Oct  5 11:24:49 +0000 2026

Классические wtmp/lastlog больше не ведутся: pam_wtmpdb и pam_lastlog2
пишут в базы SQLite без проблемы 2038 года. Неудачные попытки входа
видны в журнале службы (journald); btmp остаётся пустым.

# Захваченный вывод демо

Файлы `NN-*.txt` — транскрипты демонстраций, показываемые на слайдах компонентом
`<TerminalCapture>` (тема курса, `theme/components/`). Секции разделяются строками
вида `===== Заголовок =====`; компонент выбирает секцию по номеру или подстроке
заголовка. Поддерживаются ANSI-коды цвета (SGR): транскрипт, снятый через
`script -q -c '...' capture.txt`, отображается со стандартной раскраской bash.

Текущие транскрипты получены в одноразовой среде Ubuntu 24.04 и используются как
**иллюстративный ожидаемый вывод**. При подготовке демо-VM на Ubuntu Server 26.04 LTS
перезапишите их выводом сценариев `../demos/NN-*.sh` (нумерация файлов совпадает
с нумерацией сценариев; `10-nss-ldap.txt` снят в однохостовом варианте nslcd).

После повторного захвата сверьте координаты `TCallout` (line/col/span) на слайдах:
они привязаны к позициям символов в секции.

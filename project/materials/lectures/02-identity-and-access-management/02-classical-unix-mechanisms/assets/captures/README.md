# Захваченные выводы (captures)

Курируемые транскрипты терминальных сессий для слайдов лекции; показываются
компонентом `TerminalCapture` (секции разделены строками `===== Заголовок =====`).

Нумерация продолжает каталог демо лекции 2 (`…_old/assets/demos/01-13`); файлы
14–15 — не сценарии, а транскрипты, снятые 19.10.2026 в одноразовом контейнере
`ubuntu:26.04` (Ubuntu 26.04.1 LTS). Пользователи: `bob` (группы `bob`, `project`),
`alice` (`alice`, `adm`, `project`), `carol` (только `carol`); группа `project` —
GID 1010. Табуляция развёрнута (`expand -t 8`), иначе колонки TCallout съезжают.

- `14-object-types.txt` — сеанс пользователя `bob`, одна секция: типы объектов
  с файловым интерфейсом (`-`, `d`, `c`, `p`, `s`) и процесс в `/proc`.
- `15-identification-basics.txt` — корневой сеанс: `id`, `groups`, строки
  `/etc/group` и `/etc/passwd` для пользователей с разным членством в группах.
- `16-etc-passwd.txt` — корневой сеанс: полный `cat /etc/passwd` (в контейнере
  дополнительно установлен `openssh-server`, поэтому есть псевдопользователи
  `sshd`, `systemd-*`, `messagebus`), пример поля 2 и права доступа
  (`stat` для `/etc/passwd` и `/etc/shadow`).
- `01-passwd-uid-zero.txt` — перенесён из старой лекции (демо 01: подмена UID
  в третьем поле) и переразбит на две секции под слайд: «до» (строка + `id`)
  и «после» (sed + строка + `id`); команды и вывод не менялись. Снят отдельным
  сценарием (`…_old/assets/demos/01-passwd-uid-zero.sh`), поэтому `alice` там
  имеет UID 1001.

Остальные captures переносятся из `../../02-classical-unix-mechanisms_old/assets/captures/`
вместе со слайдами, которые на них ссылаются.

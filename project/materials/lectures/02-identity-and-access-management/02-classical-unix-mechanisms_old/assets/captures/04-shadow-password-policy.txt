
===== Создаём пользователя dave =====

# useradd -m -s /bin/bash dave

===== Строка /etc/shadow сразу после создания (пароль ещё не задан) =====

# grep '^dave:' /etc/shadow
dave:!:20731:0:99999:7:::

===== Парольная политика ДО (chage -l) =====

# chage -l dave
Last password change					: Oct 05, 2026
Password expires					: never
Password inactive					: never
Account expires						: never
Minimum number of days between password change		: 0
Maximum number of days between password change		: 99999
Number of days of warning before password expires	: 7

===== Задаём парольную политику: min=1 max=90 warn=7 inactive=14 =====

# chage -m 1 -M 90 -W 7 -I 14 dave

===== Устанавливаем пароль =====

# printf 'P@ssw0rd-1\nP@ssw0rd-1\n' | passwd dave
New password: Retype new password: passwd: password updated successfully

===== Строка /etc/shadow ПОСЛЕ смены пароля =====

# grep '^dave:' /etc/shadow

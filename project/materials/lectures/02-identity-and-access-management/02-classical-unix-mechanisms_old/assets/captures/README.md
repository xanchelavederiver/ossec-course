# Захваченный вывод демо

Файлы `NN-*.txt` — транскрипты демонстраций, показываемые на слайдах компонентом
`<TerminalCapture>` (тема курса, `theme/components/`). Секции разделяются строками
вида `===== Заголовок =====`; компонент выбирает секцию по номеру или подстроке
заголовка. Строки без ANSI-кодов компонент раскрашивает сам, как стандартную
bash-сессию: зелёное приглашение `$ `, красное `# `, жирная команда, приглушённый
хвостовой комментарий `# …`. Поддерживаются и ANSI-коды цвета (SGR): транскрипт,
снятый через `script -q -c '...' capture.txt`, отображается с записанной
раскраской (такие строки не трогаются эвристикой).

## Происхождение

Транскрипты записаны 2026-10-05 в одноразовых контейнерах **Ubuntu 26.04.1 LTS**
(образ `ubuntu:26.04`) запуском демо-сценариев вида:

~~~bash
docker run --rm -v "$PWD/demos":/demos:ro -v "$PWD/out":/out ubuntu:26.04 \
  bash -c 'bash /demos/NN-name.sh > /out/NN-name.txt 2>&1'
~~~

Для демо 05 предварительно ставится `openssl`, для демо 09 — `sudo` (в 26.04 это
sudo-rs), для демо 08 — `openssh-server sshpass wtmpdb lastlog2 libpam-wtmpdb
libpam-lastlog2`, для демо 12–13 — `procps gcc` (записаны 2026-10-18, образ
`ubuntu:26.04`, табуляция развёрнута `expand -t 8` для координат коллаутов);
установка выполняется до записи и в транскрипт не попадает.

Особые файлы:

- `08-login-accounting.txt` — снят на 26.04: классические wtmp/btmp/lastlog пусты,
  утилиты `last`/`lastb`/`utmpdump`/`lastlog` отсутствуют; входы записываются в
  wtmpdb/lastlog2.
- `08-login-accounting-2404.txt` — **исторический** транскрипт Ubuntu 24.04
  (utmpdump по btmp): слайд о формате `struct utmp` использует его с явной пометкой.
- `10-nss-ldap.txt` — однохостовый вариант nslcd; сценарии курса 10–11 используют
  SSSD и две VM.

При повторном захвате сверьте координаты `TCallout` (line/col/span) на слайдах:
они привязаны к позициям символов в секции. Нумерация файлов совпадает с нумерацией
сценариев `../demos/NN-*.sh`.

# Захваченные выводы (captures)

Курируемые транскрипты терминальных сессий для слайдов лекции 5
(разграничение ресурсов); показываются компонентом `TerminalCapture`
(секции разделены строками `===== Заголовок =====`).

Транскрипты сняты 26.10.2026 в одноразовом **privileged** контейнере
`ubuntu:26.04` (Ubuntu 26.04.1 LTS, hostname `srv`) с делегированным
механизмом `cgroup2` (`--privileged --cgroupns=private`; все контроллеры
`cpu`, `memory`, `pids` доступны в корне делегированной иерархии).
Пользователи: `bob` (UID 1001, sudo без пароля — в транскриптах `$`-prompt),
`x` (UID 1002, для демонстрации `pam_limits` по ssh). Для демо `pam_limits`
в контейнере запущен `sshd` (вход записан через `expect`).

Курирование: табуляция развёрнута (`expand -t 8`), хвостовые пробелы сняты,
листинг `ls` сведён к трём колонкам, `PID` приведены к единому виду
(`bash` — 5020), служебные строки подготовки иерархии убраны. Остальной
вывод — дословный.

- `01-ulimit-basics.txt` — `ulimit -a`; мягкий (`-S`) и жёсткий (`-H`)
  лимиты числа открытых файлов, правило «понижать — можно, повышать —
  привилегия».
- `02-ulimit-examples.txt` — пять сценариев исчерпания: дескрипторы (`-n`),
  форк-бомба (`-u`), размер файла (`-f`), виртуальная память (`-v`),
  процессорное время (`-t`).
- `03-pam-limits.txt` — постоянный жёсткий `fsize` 1024 КБ в `limits.conf`,
  применённый при входе по ssh; файл 32 КБ проходит, 2 МБ — `File too large`.
- `04-cgroup-basics.txt` — создание группы и её интерфейсные файлы; перенос
  процесса записью `PID` в `cgroup.procs`; лимит `pids.max`; удаление.
- `05-cgroup-controllers.txt` — `cgroup.controllers` vs `cgroup.subtree_control`;
  ограничение сверху вниз; поле `populated` в `cgroup.events`.
- `06-cgroup-cpu-quota.txt` — квоты `cpu.max` по иерархии `A → {P,Q,R}`;
  измерение `pidstat`: 10/15/25 % по процессу; три процесса делят 25 % группы.
- `07-cgroup-version.txt` — проверка версии: единственная иерархия типа
  `cgroup2`.

> Координаты выносок (`TCallout`) привязаны к 1-based строкам и столбцам
> секций этих файлов (после отсечения пустых строк) и проверены скриптом;
> при пересъёмке демонстраций их нужно пересчитать.
